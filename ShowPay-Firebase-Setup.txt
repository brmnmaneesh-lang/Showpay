Show Pay Firebase connection

Project: show-pay
Android package: com.showpay.app

User App:
- Firebase Authentication uses the mobile number as a private email-style login: <mobile>@showpay.app.
- Firestore collections: users, deposits, withdrawals.
- Deposit screenshots upload to Firebase Storage.

Admin Panel:
- Separate web panel.
- Admin account: admin@showpay.app / admin123. The panel creates this Firebase Auth account on first successful login if it does not exist.

Important:
1. In Firebase Console enable Authentication > Email/Password.
2. Create/enable Firestore Database.
3. Enable Storage.
4. Apply the included firestore.rules before production use.
5. The app only creates withdrawal requests; it does not perform real bank/UPI payouts.
